## 4.1 SFT 样本格式

统一转换为 conversational format。

例如：

```python
{
    "messages": [
        {
            "role": "user",
            "content": "<question>"
        },
        {
            "role": "assistant",
            "content": "<reasoning>\nFinal answer: <answer>"
        }
    ]
}
```

优先复用 GSM8K 原始 reasoning。

但是最终答案必须标准化成：

```text
Final answer: X
```

目的是：

1. 保留监督推理过程
2. 建立稳定的最终答案输出协议
3. 方便现有 answer extractor 解析
4. 为以后 GRPO format reward 留接口

---

## 4.2 禁止数据泄漏

必须实现程序化检查：

```text
train question
∩
frozen test question
=
empty
```

至少检查：

### Exact overlap

标准化 question 后做 hash comparison。

### Dataset provenance

训练 manifest 必须记录：

```text
source dataset
source split
num samples
seed
SHA-256
dataset fingerprint
generation timestamp
```

如果检测到 train/frozen overlap：

**直接失败。**

不要 warning 后继续训练。

# 十一、Failure Analysis

P1 不需要复杂研究，但必须增加一个最基本的错误分析。


```text
num_improved

num_both_wrong
```

这是 PostTrainStack 第一版真正有价值的分析能力。
